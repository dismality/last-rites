# Using MCP Tools

- **context7** gives up-to-date library documentation. Before writing code against `@react-three/fiber`, `@react-three/drei`, `@react-three/rapier`, `@react-three/postprocessing`, `zustand`, `howler` or `fast-check`, look up the current API with context7 instead of relying on memory. These libraries change between major versions.
- **GitHub** (if configured) is used for creating issues from spec tasks and checking CI. Never push or open PRs without asking.
